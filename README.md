# Industrial By-Product B2B Matching Dashboard

A Streamlit dashboard for identifying industrial waste reuse opportunities.

## Features

- Dataset Preview
- KPI Dashboard
- Waste Type Analysis
- Industry Analysis
- B2B Matching Search
- Interactive Charts

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```

## Dataset

Place your CSV file inside:

```text
data/industrial_waste.csv
```
